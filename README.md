# 📝 Django Blog Website

A fully functional **Blog Website built using Django**, where users can create, read, update, and delete blog posts.  
This project demonstrates core Django concepts such as authentication, ORM, and template rendering.

---

## 🚀 Features

- User Registration & Login
- Authentication & Authorization
- Create, Edit, Delete Blog Posts (CRUD)
- View All Blogs & Individual Blog Pages
- Responsive UI
- Secure Backend using Django
- Django ORM for Database Operations

---

## 🛠️ Tech Stack

- **Backend:** Django, Python  
- **Frontend:** HTML, CSS, Boostrap 
- **Database:** SQLite  
- **Tools:** VS Code, Git
